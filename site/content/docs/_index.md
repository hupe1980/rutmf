These guides cover the crate from both ends: **calling** a TM Forum Open API and
**serving** one. They assume you know what a TMF Open API is, but not how this
crate models it.

For per-item signatures and every type in the model, see the
[API reference on docs.rs](https://docs.rs/rutmf).
